📈 Task 2 — Exploratory Data Analysis

The second task involved performing Exploratory Data Analysis (EDA) using Microsoft Excel.

Descriptive statistics were calculated to better understand the numerical variables in the dataset.

Statistical Measures

The analysis included:

Mean — the average value of a variable.
Median — the middle value when the observations are arranged in order.
Count — the number of observations in the dataset.

These measures helped provide a basic understanding of the distribution and characteristics of the data.

📊 Excel Dashboard

After completing the data cleaning and analysis, an Excel dashboard was created to visually present the results.

The dashboard was created entirely using Microsoft Excel.

It provides a visual summary of important information from the dataset through:

Key metrics
Charts
Tables
Product analysis
Sales information
Order-related analysis

The dashboard was designed to make the results easier to understand and communicate.
